# Additional steps to build successfully:

1. Install required system dependencies:
   sudo apt-get update
   sudo apt-get install -y pkg-config libssl-dev

2. Initialize git submodules (required for moonlight-common-c):
   git submodule update --init --recursive

3. Build the project:
   cargo build --release
